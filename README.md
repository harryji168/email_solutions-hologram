# Hologram sample

A sample 3D "hologram" page: a made-up one-bedroom apartment that you can
rotate and zoom in the browser, and place in your real space with the phone
camera (AR) through the **View in your space** button.

- `index.html` - the page, using Google's `<model-viewer>`
- `apartment.glb` - the 3D model, about 45 cm wide in AR

Open the GitHub Pages address of this repository on a phone
(Safari on iPhone, Chrome on Android).
