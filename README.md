# Hologram sample

A sample 3D hologram page: a made-up one-bedroom apartment that looks like a
solid miniature sitting inside the phone. Tilt the phone to look around it,
drag to turn it, pinch to zoom.

- `index.html` - the page (three.js, off-axis projection driven by phone tilt)
- `apartment.glb` - the 3D model

Open the GitHub Pages address of this repository on a phone. On iPhone, tap
**Start hologram** and allow motion access.
